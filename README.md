## SAST Tool

SonarQube Community Edition was used for Static Application Security Testing (SAST).

## Suggested Vulnerabilities

The application demonstrates security vulnerabilities relevant to an E-Commerce application:

1. SQL Injection
2. Cross-Site Scripting (XSS)
3. File Upload Vulnerability

## SonarQube Findings

SonarQube analysis identified the following issues:

- CSRF protection issue
- HTTP methods not explicitly specified
- Debug mode enabled

Total issues identified by SonarQube: 4.
